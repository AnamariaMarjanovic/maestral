# ADR-0016: Logo: wind in the sail

- **Status:** Accepted
- **Date:** 2026-11-12

## Context

The docs site used the sail shape token as a placeholder logo: a square with
three rounded corners. It tied in with the components but was not a mark
anyone would remember or recognise as a favicon.

## Decision

- The logo is **a mainsail with three gusts of wind drawn across it**. The
  name, the visual identity (ADR-0011) and the mark now tell one story: the
  maestral fills the sail.
- The gusts are **cut out of the sail with an SVG mask**, not painted in the
  background color, so the mark works on any background and in both themes.
  The gusts start inside the sail so the mast edge stays whole; an earlier
  version cut through it and read as stacked strips at small sizes.
- The inline mark uses `currentColor` and takes `--ms-color-primary`. The
  favicon (`projects/docs/public/favicon.svg`) and the README logo
  (`docs/assets/logo.svg`) switch color with `prefers-color-scheme`.
- The favicon has two thicker gusts instead of three, so it stays legible at
  16 px.

## Alternatives considered

- **Two sails** (mainsail and jib): clear silhouette, but generic.
- **Compass rose** with the north-west point highlighted, where the maestral
  blows from: a good story, but too detailed at small sizes.
- **An M made of two sails**: the most original monogram, but further from
  the wind story.

## Consequences

- One SVG path and mask, easy to reuse and to recolour through tokens.
- The Angular default `favicon.ico` is no longer referenced.
